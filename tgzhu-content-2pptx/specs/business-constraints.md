# 商务风排版约束（唯一权威源 · McKinsey 咨询风，白底深字）

> 引用：`engines/business.py` 按此表渲染。
> 无模板 — 从空白 `Presentation()` 构建，白底深字 + 行动标题（McKinsey 咨询风，不依赖企业模板）。

## 风格定位

- 身份：McKinsey 式咨询布局（结论式 action title + 浅灰卡 + 左侧品牌青竖线 + 金色高亮行），沿用企业品牌色。
- 与企业风的区别：企业风标题巨号 + 圆角边框卡（深蓝底白字）；商务风标题置顶左小号 + 浅灰卡无边框 + 左青竖线，更"咨询"。整页白底深字。

## 防损清理（save 时）

`full_cleanup()` 在保存后重打包 pptx：
- 删除所有 `.xml` 中的 `<p:style>` 节点（避免继承主题样式）
- 删除 theme 中的 `outerShdw / innerShdw / scene3d / sp3d`（去阴影/3D，保持扁平商务感）

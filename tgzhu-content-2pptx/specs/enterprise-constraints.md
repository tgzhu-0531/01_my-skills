# 企业风排版约束（唯一权威源）

> 字号层级（角色→pt/bold）定义在 `engines/common.py::TYPOGRAPHY`，颜色定义在 `engines/enterprise.py::ENT_PALETTE`。
> `enterprise.py` 通过 `apply_role(tf, role, text, ENT_PALETTE)` 按角色渲染，不散落硬编码数值。
> 本文件为权威对照表；修订字号/颜色请同步改 common.py / enterprise.py 两处源。
> **设计原则（居中对称 / 2×2 箭头 / 框内五区 / 专家补充）为跨风格通用强制规则，唯一权威源见 `SKILL.md` 第 4.12 节**，本文件仅承载企业风专属参数（色值/字号/坐标），时间轴行为其落地样板。

## 定义对比 (definition_compare)（沉淀自定义对比迭代）

> **何时用**：一页要同时讲"是什么"和"不是什么/边界在哪"——定义类/概念解释页。
> 典型信号：内容含"定义 + 排除项（≠ / ❌×n + ✓×1）"的叙事流向。纯并列对比（同权两栏）用 `two_column`，勿混用。
> **视觉语言核心**：排除法（≠ / ❌×n + ✓×1）比"不同于"文字冲击力强 10 倍（PPT 快速阅读黄金法则）；排除项视觉降温、正解视觉跳出来。

| 元素 | 约束 |
|:----|:----|
| 整体布局 | 非对称左右分区：左宽 58%（0.6→7.5）/ 右窄 42%（8.0→12.9）；中部细竖线 x=7.80（`#2A3A4D`，0.75pt）明确分区；内容区 1.85→6.30 垂直居中（与时间轴一致，跨页统一） |
| 左区 hero | FDE 类缩写 48pt Bold `#00AFD2`（视觉锚点）；英文全称 16pt 斜体白；中文译名 18pt Bold `#00AFD2` → 三级术语层级 |
| 左区要点 | 青点 OVAL 0.1×0.1in `#00AFD2` + 文字 14pt `#E5E5E5`，dot y=by+0.07 偏移贴合文字中线 |
| 左区总结 | 底部强调句 15pt Bold `#00AFD2`（承载"是什么"的结论） |
| 右区对比标题 | `FDE ≠ …` 18pt Bold `#FFFFFF`（用 ≠ 符号，不用"不同于"） |
| 排除项 ○ | OVAL 0.34×0.34in，底 `#3A4654`（暗灰降温），内 × 16pt Bold `#9AA5B0`；**圆 y=ry+0.05 偏移、文本框 y=ry 不偏移、文本框高 0.45in ≥ 圆直径 → 圆心与文字中线对齐**（对齐铁律） |
| 排除项文字 | 关键词 18pt Bold `#9AA5B0`（与对比标题同级，不缩于左侧正文）；描述 15pt `#7C8894`（"  "双空格分隔） |
| 正解项 ✓ | 圆角框 0.95in 高，底 `#10333E` + 边 `#00AFD2` 1pt；○ 底 `#00AFD2` 内 ✓ 14pt 白；文字 14pt Bold `#00AFD2`（视觉跳出来，与排除项形成冷暖/明暗对比） |
| 行高 | 排除项 0.68in（放大字号留呼吸）；末条排除项与正解项间距 ≥0.2in |

## 价值闭环 (value_loop)（沉淀自价值闭环迭代）

> **何时用**：一页要表达"四大价值 / 业务闭环 / 循环模型"——内容不是并列能力点，而是一套持续运行的交付模式。
> 典型信号：金句含"闭环 / 持续运行 / 循环"等词（如"不是功能，而是一套业务闭环"）。纯四宫格并列能力用 `card_grid`，勿混用。
> **视觉语言核心**：用"紧凑对称 2×2 四卡片 + 四箭头等长循环"把抽象"闭环"概念图形化（比四张独立卡片高一个维度）。**无中心圆**（中心圆非本风格强项，易显贴纸感）；等边箭头→四卡上下左右间距全等、整簇水平居中（左右留白相等），把视觉重心交还给框内内容；箭头仅作"闭环"语义提示、配色退到钢蓝不抢戏。

| 元素 | 约束 |
|:----|:----|
| 整体布局 | 紧凑对称 2×2 四卡片（**无中心圆**）+ 四箭头等长循环：卡片**宽 4.80in 高 2.1in**；**卡宽由正文内容实测算出**（微软雅黑 12pt 最长正文行含「· 」=4.042in → CW=4.042+内边距0.6+缓冲0.15=4.80，不凭感觉撑满）；中缝(箭头长) **L=gap_v=gap_h=0.5in 四向全等**→四卡上下左右间距全等；**整簇宽=2×CW+L，水平居中、左右留白相等**（CW 由正文内容实测、随文章不同，勿写死）；四卡片 01左上/02右上/03右下/04左下（顺时针闭环）；垂直 **TY=y0=1.78**→下行底 6.50，底部金句 6.65 不重叠；满足 4.12 |
| 卡片底 | ROUNDED_RECTANGLE **无填充（透明）+ 极淡贴背景边框 `#D2D8DC` 1.25pt**（ENTER_CARD_LINE，2026-08-01 由亮青 #00AFD2 退背景，内容聚焦、不压页面） |
| 编号 | **28pt Bold `#00AFD2`**（左上角放大，作卡片主标识，存在感高于标题）；与标题同一行、标题垂直居中贴编号 |
| 标题 | 16pt Bold `#FFFFFF` **左对齐**（与编号同行，title_card 角色），垂直居中于编号行 |
| 要点 | **12pt** `#E5E5E5` 左对齐，"· "前缀；**间距遵循逐级递减：标题↔正文 > 段间 > 行距**（对齐 SKILL §4.12-7 通用红线）；solve=True 自适应字号+间距填满卡高，编号 20–28pt（3 要点内容取小值以保不溢出） |
| 分隔线 | 卡内水平线 **`#44586C` 略亮蓝灰 1pt**（比旧 `#2A3A4D` 可见、仍明显低于结论青高亮），位于正文与结论之间（y+1.52） |
| 结论 | **16pt Bold `#00AFD2` 底部居中**（记忆钩子），位于分隔线下方（y+1.59），不与正文重叠 |
| 循环箭头 | 4 段等长直线 connector（MSO_CONNECTOR.STRAIGHT），**3pt `#7A99B3` 钢蓝**（比亮青 `#00AFD2` 沉稳、不抢框内内容），tailEnd triangle(med)（顺时针：顶→、右↓、底←、左↑），四箭头长度均=L=0.5in |
| 坐标样板 | **由 `layout_value_grid` 动态计算，勿硬编码**：左列 x=x0、右列 x=x0+CW+L；上行 y=y0、下行 y=y0+卡高+L（卡高=(y_end-y0-L)/2）；四卡顺时针 01左上/02右上/03右下/04左下；四箭头 connector 在卡外成环（顶→、右↓、底←、左↑）。示例（CW≈5.25、L=0.5、y0=1.78 时）：左列 x≈1.17 / 右列 x≈6.92；上行 y=1.78 / 下行 y≈4.39；卡片 左上(1.17,1.78) 右上(6.92,1.78) 右下(6.92,4.39) 左下(1.17,4.39)。具体坐标以代码输出为准。 |
| 约束 | 左右留白相等（x0=(13.333-2×CW-L)/2）；卡片右缘=x0+2×CW+L≤13.33、下缘≤6.50，零越界；卡片两两零重叠；底部金句 6.65 不与卡重叠 |
